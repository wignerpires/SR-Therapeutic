## 📖 Sobre o Projeto

O **SR Therapeutic** é um aplicativo mobile desenvolvido para auxiliar profissionais de acupuntura na organização de seus atendimentos, agenda, cadastro de pacientes e acompanhamento da evolução clínica.

A proposta do sistema é substituir o uso de agendas físicas e aplicativos de mensagens por uma solução digital **simples, prática e intuitiva**, proporcionando maior organização dos atendimentos e facilidade no acesso ao histórico dos pacientes.

---

## 🎯 Objetivo do Projeto

O objetivo do **SR Therapeutic** é desenvolver um **MVP (Minimum Viable Product)** capaz de centralizar as principais atividades relacionadas à gestão de atendimentos de profissionais de acupuntura.

O sistema busca facilitar a organização da rotina profissional, permitindo o gerenciamento de pacientes, atendimentos, agenda, evolução clínica e informações financeiras.

### Principais objetivos:

- 🔐 Login e cadastro de usuários
- 📅 Organização da agenda
- 👤 Cadastro e gerenciamento de pacientes
- 📋 Histórico dos atendimentos
- 📈 Registro da evolução clínica
- 💰 Controle financeiro básico

---

## ⚙️ Funcionalidades do MVP

O MVP do **SR Therapeutic** possui as seguintes funcionalidades:

| Funcionalidade | Descrição |
|---|---|
| 🔐 **Login** | Permite o acesso do usuário ao sistema |
| 📝 **Cadastro** | Permite o cadastro de usuários |
| 📅 **Agenda** | Organização dos atendimentos |
| 👤 **Pacientes** | Cadastro e gerenciamento dos pacientes |
| 📋 **Histórico** | Consulta ao histórico dos atendimentos |
| 📈 **Evolução** | Registro da evolução clínica dos pacientes |
| 💰 **Financeiro** | Controle financeiro básico dos atendimentos |

O projeto foi desenvolvido utilizando as seguintes tecnologias:
